# AU·RA V0.1 — MVP

## Goal

Create a credible artist-development and management platform that delivers immediate value to emerging artists while giving a boutique agency a scalable scouting and management workflow.

## Core artist promise

**Know where you stand. Know what to do next.**

The artist should receive useful value before representation. Representation is an outcome to unlock, not the only reason to join.

## Artist journey

### 1. Create profile
Capture:
- Artist/stage name
- Location
- Genres
- Bio
- Social links
- Streaming links
- Current representation / booking status
- Live experience
- Release history
- Press photos
- EPK assets

### 2. Upload music
Artist can upload a demo or private track and add:
- Track title
- Genre/subgenre
- Release status
- Planned release date
- Collaborators
- Private streaming link or audio upload
- Artwork

### 3. AU·RA Assessment
Generate a transparent assessment across:
- Music readiness
- Release readiness
- Brand readiness
- Audience / traction
- Live readiness
- Professional setup
- Momentum

Do not present a score as objective truth. Every score must be accompanied by evidence and actionable recommendations.

### 4. Representation Readiness
Show:
- Overall readiness percentage
- Strongest dimensions
- Biggest gaps
- Required next actions
- Eligibility state

Example states:
- Building
- Developing
- Nearly ready
- Eligible for agency review
- Under review
- Representation candidate

### 5. Next Moves
Create a prioritized action list such as:
- Complete EPK
- Add live performance footage
- Prepare next release campaign
- Improve artist bio
- Build stronger release consistency
- Submit upcoming track for internal review

### 6. Apply for representation
Representation application becomes available when required profile data is complete and/or the agency manually enables it.

No guarantee of representation, label placement or bookings.

## Agency journey

### Dashboard
At-a-glance:
- New applications
- Artists needing attention
- Releases requiring action
- Follow-ups due
- Open opportunities
- High-potential scouting candidates

### Scouting inbox
Managers can:
- Review applicants
- View assessment
- Add internal notes
- Assign stage/status
- Reject / watch / development / representation review

### Roster
Manage signed/development artists with:
- Artist profile
- Timeline
- Strategy
- Tasks
- Releases
- Opportunities
- Contacts involved

### Releases
Pipeline:
Demo → Internal review → Ready to pitch → Pitching → Interest → Negotiation → Signed → Scheduled → Released

### Network CRM
Private relationship layer for:
- Labels
- A&R contacts
- Booking agencies
- Bookers
- Promoters
- Venues
- Media / partners

Relationship data is never exposed directly to artists by default.

### Opportunities
Examples:
- Relevant label target
- Booking opportunity
- Showcase
- Collaboration
- Playlist/media opportunity
- Development opportunity

Every opportunity has fit, rationale, owner, status and next action.

### AU·RA Intelligence
AI may:
- Summarize artist status
- Suggest next actions
- Prepare release strategy
- Draft internal pitch notes
- Suggest relevant contacts/opportunities based on internal data
- Summarize relationship history
- Flag overdue follow-ups

AI must not autonomously contact industry relationships in V0.1.

## Non-goals for V0.1

Do not build yet:
- Full royalty accounting
- Public gig marketplace
- Automated contract negotiation
- Fully autonomous outreach
- Complex streaming analytics warehouse
- Public label directory
- Pay-to-pitch marketplace
- Guaranteed placement mechanics

## Business model hypothesis

### Explorer
Free artist profile + basic readiness + next moves.

### Development
Paid artist-development layer with human review and strategy.

### Representation
Selective commission-based management / representation.

### Future B2B
License AU·RA to other boutique artist managers/agencies.

## Success criteria

V0.1 succeeds if:
1. An emerging artist gets useful feedback without being represented.
2. A manager can assess applicants much faster than manually.
3. The system creates a repeatable development path.
4. Agency relationships stay private and controlled.
5. The manager can clearly see the next action for every active artist or release.
